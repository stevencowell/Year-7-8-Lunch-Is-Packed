1 Design brief evidence lab

Your goal

Turn the need into testable design direction.

Separate what the product must achieve from the features that are still open to design.

Save this evidenceA need statement, user profile, constraints and five testable criteria.
Read this image in words: the concepts change form and carrying method while the materials and tools make production constraints visible.
  1. Name the packed-lunch problem without prescribing a solution.
  2. Describe the user before selecting features.
  3. List real constraints and leave unknown project facts as Teacher to confirm.
  4. Write criteria that name a test or observation.
